# Install Anaconda for Windows

Anaconda is an open source data science and artificial intelligence distribution platform for Python. You can use it to develop and manage data science and AI projects.

To install Anaconda:

1. Download the installer from the [official website](https://www.anaconda.com/download).

2. Select the preferred version. For this article, we are going to choose the standard **Anaconda Distribution**.

    ![Anaconda distribution](../../assets/anaconda-distribution.png)

3. Launch the downloaded EXE file.

4. Click **Next** to proceed with the installation.

5. Click **I Agree** to accept the license aggreement.

6. Select which users to install for. If you dont have admin privileges, choose **Just me**.

7. Choose the installation folder.

8. Configure the advanced installation options.

9. Click **Install**.

After the installation is complete, you can open the Anaconda Navigator and start creating your own projects.
